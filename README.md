# 受注・製品管理（iPadオフライン版）

## iPadへの入れ方（最初の1回だけネットが必要）

このフォルダの中身をどこかのWebサーバー（HTTPS）に置き、iPadのSafariで開いて「ホーム画面に追加」します。
無料で簡単なのは GitHub Pages です。

1. GitHub に新しいリポジトリを作成（Private でも Pages は使えますが、Free プランは Public のみ）
2. このフォルダの全ファイル（index.html, sw.js, manifest.webmanifest, アイコン3つ）をアップロード
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
4. 表示された URL（https://ユーザー名.github.io/リポジトリ名/）を iPad の Safari で開く
5. 共有ボタン → 「ホーム画面に追加」
6. 以後はホーム画面のアイコンから起動。機内モードでも動きます

※ データ（注文・製品・写真・図面）は iPad の中だけに保存され、サーバーには送られません。
　URL を知られても、他人に見えるのは空のアプリだけです。

## 注意

- データは iPad 内のみ。**設定タブの「書き出す」で定期的にバックアップ**してください。
- ホーム画面アプリを削除すると、データも消えます。
- アプリを更新するときは、ファイルを差し替えたうえで `sw.js` の `VERSION` を変更してください（次回起動時に反映）。
- 音声ボタンは Apple の音声認識を使うため、オフラインでは使えないことがあります。その場合はキーボードのマイクボタン（音声入力）を使ってください。
